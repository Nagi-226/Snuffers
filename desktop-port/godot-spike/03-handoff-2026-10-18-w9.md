## 3. 给下一棒的注意事项

1. **55 MB 级 GLB 都在工作树里、未入库**（`em57p.glb` / `em68a.glb` 已由机主裁决入库为 `64d67d7`；`*_viewmodel.glb` 是否入库仍按机主 10-18 裁决 = 不入库）。不要 `git add .`，只精确 add 脚本 + 报告 + JSON。
2. **不要覆盖已交付的输出**：`weapon_postprocess.py` 默认输出到输入同目录的 `<stem>_viewmodel.glb`，重跑会覆盖。要重跑请显式传第二个参数。
3. **执行通道**：本机 DSH 的 `pwsh` 工具 100% 崩溃（退出码 3221225794 / 0xC0000142），唯一可用通道是 `modeling/tools/subproc/`（`runner.gd` + `cmd.json`，由 `godot_run_headless` 拉起，读同目录 `cmd.json` 的 `{exe,args,timeout}` 并回传 `last.log`）。该目录**故意保留且不入库**。
   - 坑 1：`runner.gd` **不切换 cwd** → 命令里的路径必须绝对。
   - 坑 2：子进程 stdout 是 GBK，中继按 UTF-8 解码会出乱码（数字/路径不受影响，完整日志读 `last.log`）。
   - 坑 3：`cmd.exe` 批处理文件若用 LF 换行会报 `'xxx' 不是内部或外部命令`，**别用 .bat**，直接让 python 的 `subprocess` 编排。
4. **工作树里有别人的未提交改动**（51 个 `godot/assets/**/*.import` + `desktop-port/godot-spike/07-snuffers-art-design.md` 及其未跟踪文件），**不要碰、不要 commit**。
5. **渲染目录 `renders_em57p/` 体积大且不入库**：`colors/` `hl/` `hl2/` `iso/` `detail/` 是标定证据，`whole_*` `part_*` `body_rest_*` 是报告引用的成品对照图。
6. **新增武器标准流程**（已脚本化）：① `PROFILES` 加档 + 写 `_classify_<stem>`；② 六视角转面渲染确认朝向与布局；③ top-N 分量上色定位大件；④ 规则高亮 → 逐集合隔离两轮收敛阈值；⑤ 跑管线；⑥ `verify_glb_identity.py` 独立校验；⑦ 写 md/json 报告；⑧ em68a 回归 sha256 必须不变。
