# 11 — 城中村地铁站（地面→地下无缝连通）可行性探讨

> **日期**: 2026-09-27 | **作者**: Kimi Work（桌面行动层） | **状态**: 可行性探讨，待机主裁决排期
> **需求（机主原话）**: 地铁站口在地面街道上，玩家直接走下去——沿途扶梯、站厅、站台，
> 参考广州地铁站；**不要**"进地铁口→加载→直接出现在站内"的场景切换形式。

---

## 1. 结论

**可行，且 Godot 4.6 对这类"同场景垂直地下层"没有引擎级障碍。**
无缝地下场景的本质就是"在街道几何下方 -8~-16m 处继续搭几何"，不需要任何场景切换技术。
真正的工作量在内容搭建（站厅/站台/隧道）和三个技术细节（光照隔离、雾切换、扶梯表现）。
建议按 S1→S3 三个阶段并入路线图，在街道布景层收尾后动工。

## 2. 空间结构（广州地铁特征拆解）

| 层 | 深度 | 内容 |
|---|---|---|
| 出入口（地面） | ±0m | 玻璃钢结构雨棚、立柱、线路标识立柱牌（做 EDAA 架空城市轨交 Logo，不用羊角）、下行扶梯 ×2 + 中间楼梯、无障碍电梯井（可只做外壳） |
| 站厅层 | -6~-8m | 安检机、闸机排、售票机、吊顶灯带、瓷砖墙面、导向吊牌、广告灯箱 |
| 站台层 | -12~-15m | 站台屏蔽门、轨道槽（下方暗沟）、对向隧道口（黑洞+微光+红色信号灯）、立柱、座椅 |
| 隧道（延展） | 站台两端 | 拱形隧道段，寄生体巢穴的天然栖息地（孢子囊/菌毯大有可为） |

选址：布局表 `ALLEYS[]` 里挑一块巷道/空地放出入口（不占用建筑占位），
井道在街面投影之外垂直下探，站厅/站台向街道正下方或街区外延伸均可——
地下层与地上建筑占位互不冲突（垂直分层）。

## 3. 技术要点与对策

| # | 问题 | 对策 | 风险 |
|---|---|---|---|
| ① | **全局夜雾会灌进地下**（当前 NIGHT_FOG 是 Environment 全局指数雾） | 区域切换：出入口井道中段放一个 Area3D 触发体，玩家穿越时 tween 把 `fog_density` 在 0.065↔0.004 间渐变（约 1s），同时渐变环境光色温（地下为灯光暖白）。Claude-of-Duty 散射/消光分离哲学同样适用：地下能见度由灯光射程决定 | 低，标准手法 |
| ② | **天空环境光漏进地下**（ambient_light_source=天空，地下会被"照亮"） | 地下不靠环境光：站厅/站台用自发光灯带材质（emission）+ 少量 OmniLight/SpotLight 关键点；井道过渡段用环境光自然衰减即可（越深越暗）。若不够再考虑 ReflectionProbe/GI 遮蔽，spike 阶段不做 | 低 |
| ③ | **扶梯表现** | spike 级：扶梯做成 30° 斜坡静态几何 + 台阶贴图 UV 缓慢滚动（shader `UV.y += TIME*speed`）+ 扶手带同步滚动，玩家走上去就是"在乘扶梯"；进阶再加 Area3D 传送带推力（velocity 叠加）。台阶级进/梳齿板细节不做 | 低 |
| ④ | **碰撞与寻路** | 楼梯/坡道一律用斜坡碰撞体（不用踏步碰撞，FPS 角色控制器走斜坡不卡脚）；敌人 NavigationMesh3D 对坡道可烘焙，寄生体下地道追人可行 | 低 |
| ⑤ | **性能** | 地下几何常驻内存但规模小（一个标准站约等于半条街的体量）；配合 ① 的 Area3D 可做简单可见性开关（玩家在地下时隐藏天际线环带与街道道具层，反之亦然） | 低 |
| ⑥ | **招牌/标识文字** | AI 生成贴图易带真实城市文字（立面 neon 贴图已踩过一次"深圳"），站内导向牌/广告灯箱贴图生成时 prompt 必须写死"无文字或用 EDAA 架空文字" | 中，已在立面贴图验证过解法 |

## 4. 工作量粗估（以试验街为基准）

| 阶段 | 内容 | 粗估 |
|---|---|---|
| S1 井道 | 出入口雨棚 + 扶梯/楼梯井道 + 雾切换触发体 | ≈ 0.5 个试验街工作量 |
| S2 站厅 | 站厅壳体 + 闸机/售票机道具（Blender 烘焙沿用现有管线）+ 灯带材质 | ≈ 0.8 |
| S3 站台+隧道 | 站台 + 屏蔽门 + 轨道槽 + 隧道段（巢穴预留） | ≈ 1.0 |

## 5. 建议

1. 先完成街道布景层（道具/电线/店面），街道"像个地方"之后再向地下延伸；
2. S1 井道单独先做一个垂直切片验证雾切换与光照过渡手感，再铺 S2/S3；
3. 地铁站是寄生体巢穴叙事的天然容器，建议剧本侧同步确认站点在剧情中的功能（路过/战斗/巢穴核心）。

## 6. 地图分段架构探讨（2026-09-27 机主议题：分段加载 vs 一体化）

> **议题**: 旧城区街区 与「地铁口街区 + 整个地铁站地下场景」之间——
> A）半衰期式分段：自动存档点 + 过渡结构（铁栅栏门/扶梯井道）后台换图；
> B）全部一体化同场景。机主担心 B 太占资源。

### 6.1 资源账先算清楚

- 一体化场景的内存大头不是几何而是**贴图与光照数据**：当前街区 AI 贴图共 ~15MB，
  地铁站新增瓷砖/灯箱/导向牌贴图估计 +20~30MB——一体化本身并非不可承受；
- 真正的隐性成本在**工程侧**：① Godot 没有 UE5 World Partition 那种内置世界流送，
  一体化大世界想控内存就得自己手写分块流送——等于绕一圈重新发明 A 方案，还更难调；
  ② 单一大场景文件与多 Agent「文件所有权互斥」规范冲突（一张图多人改必撞车）；
  ③ 未来若继续加街区（城中村 B 区、CBD 边缘、隧道巢穴），一体化会无限膨胀。
- 半衰期（HL1/HL2）的真相：所谓"存档点加载"其实是**触发器换图 + 玩家状态跨图携带**，
  过渡走廊/电梯井是预留在两张图里的重叠区，加载藏在走电梯的几秒里。

### 6.2 裁决建议：**A 方案（分段 + 气闸过渡）**，理由三条

1. **线性 FPS 结构天然匹配**：本作是任务制线性突围流程，分段换图是行业标准做法，
   内存有界、60fps 目标好守；
2. **气闸素材现成且契合题材**：城中村防疫闸口式铁栅栏门、地铁站扶梯井道，
   都是天然的"加载隧道"——扶梯下行 8~10 秒足够 `ResourceLoader` 线程化加载整张地下图，
   玩家毫无感知；
3. **多 Agent 友好**：每张地图独立场景文件，owner 清晰，符合 AGENTS.md 文件所有权互斥。

### 6.3 A 方案落地形态（配合 §2 空间结构）

| 分段 | 文件 | 气闸过渡 |
|---|---|---|
| 街区 A（城中村试验街扩展） | `street_oldtown_a.tscn` | 铁栅栏门 + 短巷（开门动画期间后台预取下一段） |
| 街区 B（地铁口街区） | `street_oldtown_b.tscn` | 地铁口雨棚 + 扶梯井道（下行过程加载地下图） |
| 地铁站（站厅+站台+隧道） | `metro_station.tscn` | 上行扶梯反向同理 |

### 6.4 前置依赖（动工前必须具备）

1. **轻量存档系统**（当前 spike 没有）：换图触发点自动存档——玩家状态（血量/弹药/武器）
   与任务旗标经 GameState 序列化落盘，下图载入后恢复。这是 A 方案唯一的硬前置，
   建议单独立项排期（参考 godot 技能存档模式）；
2. **换图触发器与加载屏策略**：Area3D 触发 → `load_threaded_request` → 到位后切换；
   加载超时兜底显示静态过场画面（几乎不会触发，本地磁盘加载很快）；
3. 雾/环境光参数随图切换：每张图自带 Environment 配置，换图即切换，无需渐变兼容层。

### 6.5 结论

A 方案（分段 + 气闸）进路线图；B（一体化）否决，理由见 6.1。
待机主裁决：① 是否采纳 A；② 存档系统立项排期位置；③ 地铁 S1 井道归属街区 B 还是独立图。

### 6.6 机主裁决与「无割裂过渡」设计铁律（2026-09-27）

**裁决**: 采纳 A 方案。**约束（机主原话）**: 加载后边地图后，之前走过的地图
不能在背后被刷成"漆黑虚空"——过渡必须发生在看不到之前地图的位置，
如同半衰期系列：曲折走廊里、门后、扶梯折返平台。

落地铁律（验收基准）：

1. **视线封锁原则**：换图触发点必须位于"看不到上一张图任何内容"的位置——
   L 形拐角后、关闭的门后、扶梯井道折返平台。触发点放置的验收方式：
   站在触发点用自由相机向旧图方向看，视锥内不得出现旧图任何几何。
2. **重叠区双份建造**：过渡结构（短巷/井道）在相邻两张图里各建一份一模一样的。
   新图载入后，玩家身后是**真实的过渡段几何 + 已关闭的门/闸**，
   不是贴图假象，更不是虚空。
3. **叙事化封死退路**：换图完成后旧方向的通路以题材内理由锁死
   （铁闸门落下、瓦砾塌方、闸机断电），玩家回头看到的是封闭结构。
   spike 期单向通过；双向自由往返留待正式版评估。
4. **三处过渡点设计**：
   - 街区 A→B：铁栅栏门 + L 形短巷，拐角处触发；
   - 街区 B→地铁站：扶梯井道折返平台（广州地铁两段折返扶梯形制）触发，
     井道壁天然全遮蔽；
   - 反向（站台→地面）：上行扶梯同构处理。
5. **验收用例**：换图后立即回头 180° 截图，画面中不得出现未封闭的空洞/虚空；
   过渡段几何在新旧两图中的位置偏差须为 0（同一组坐标常量驱动）。
