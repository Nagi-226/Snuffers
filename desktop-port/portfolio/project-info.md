# 《熄烛者》Snuffers — 项目展示信息

## 项目名称

《熄烛者》（Snuffers）

## 功能介绍（可直接填写，800 字以内）

《熄烛者 Snuffers》是一款基于 Godot 4.6.2 与 GDScript 开发的第一人称战术射击游戏。项目包含街区与工业仓库两个正式关卡，以及综合武器测试靶场。已实现突击步枪、手枪、冲锋枪、霰弹枪、精确射手步枪和高斯狙击枪等多类武器，支持全息瞄具、狙击倍率切换、目标搜索、实时测距与充能射击。角色具备夜视、装甲减伤、隐形和力量强化能力，配套能量消耗、敌人察觉度及状态反馈。游戏还包含独立换弹动作、共享弹药、武器栏切换、命中与爆头判定、敌人 AI、昼夜切换、小地图和任务引导。核心配置、运行状态和事件通信集中管理，并建立覆盖契约、场景、武器及集成功能的自动化测试。

## 技术栈

- 引擎：Godot 4.6.2
- 语言：GDScript
- 架构：GameConfig 参数契约、GameState 运行状态、Events 信号总线
- 内容：第一人称枪臂与换弹动画、多武器瞄具、敌人 AI、纳米模式、夜视与昼夜系统
- 验证：脚本静态检查、场景冒烟、契约断言、武器专项和实机图形探针
