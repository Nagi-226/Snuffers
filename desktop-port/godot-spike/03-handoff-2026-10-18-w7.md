## 二、HUD 层级实测结论（派单硬性设计要求 3）

**实测事实**：`hud.tscn:59` 的 `HUD` CanvasLayer **没有写 `layer` 属性 = 默认 1**；
本 overlay 原为 `layer = 100` ⇒ **夜视膜盖在 HUD 之上**。全仓库 CanvasLayer 层级清点：
`NightVisionOverlay`（脚本设）、`HUD`=1、`day_night_demo` 的 `UI`=1、`MissionEndScreen`=20，
无其他 layer 0 节点。

**两种情况各一张图**：

| 图 | layer | 观感 |
|---|---|---|
| `hud_layer100_main.png` | 100（原值） | 准星仍可读（亮十字），**但血条的红/绿/蓝色彩编码被染成同一种绿**、HUD 文字泛绿、四角被暗角压暗 |
| `hud_layer0_main.png` | 0 | HUD 完全清晰、血条保留色彩编码；**世界侧夜视效果与 layer 100 完全一致** |

**裁决**：派单字面触发条件是「盖住准星导致不可读」——准星其实可读；但血条色彩编码丢失是
同一类的可读性回归（机主对违和感极敏感，红条变绿条属明显违和），故**调整为 `layer = 0`**：
膜只处理 3D 画面，HUD/MissionEnd 全部在其上。`hud_layer_default_main.png` 是改默认值后的
复跑，与 `hud_layer0_main.png` 字节数一致，确认出厂默认即为 layer 0。

**若蜂后/机主想要「HUD 也被夜视染色」的 diegetic 观感**：把 `night_vision_overlay.gd`
`_ready()` 里 `layer = 0` 改回 `layer = 100` 即可，一行回滚，无其他依赖。

## 五、关键技术发现（下一棒必读）

### 1. `hint_screen_texture` 的官方语义（已查官方文档，非记忆）

```glsl
uniform sampler2D screen_texture : hint_screen_texture, repeat_disable, filter_nearest;
vec3 c = textureLod(screen_texture, SCREEN_UV, 0.0).rgb;   // 必须用 SCREEN_UV，不是 UV
```

- **首个**使用该 hint 的材质触发全屏 back-buffer 拷贝；**同帧第二个采样者读到的是旧缓冲**
  （「In 2D, if shaders that use hint_screen_texture overlap, the second one will not use the
  result of the first one」）。本 overlay 是场景内唯一采样者，安全；**将来若再加第二个全屏
  后期，会静默采到不含第一个效果的旧画面**——这是高发知识幻觉点。
- 采样范式直接取自官方 brightness/contrast/saturation 示例，本班只替换了色调映射部分。

### 2. 过曝趋白必须**显式**做，乘性绿 tint 永远到不了白

`g * phosphor`（phosphor 的 R/B < 1）意味着亮源的 R/B 通道永远 < G，clamp 后是「饱和绿」
而不是「白」。真实夜视仪的白亮斑来自传感器 blooming，所以 shader 里有一项显式回灌：
`bloom = smoothstep(bloom_start, bloom_start + bloom_width, luma)` 后
`mix(tinted, vec3(1.0), bloom * bloom_strength)`。**删掉这两行，应急灯/亮窗会变成死绿**。

### 3. GDScript 单引号 `"` 多行字符串是合法的（实证）

`_NV_SHADER_CODE` 用单个 `"` 起、跨行、单个 `"` 收，`tests/check_scripts.gd` 编译通过。
不是笔误，别「顺手」改成 `"""`（会引入额外缩进问题）。

### 4. `greybox_arena.tscn` / `main.tscn` 没有 `--shot` 处理

`--shot` 只存在于 `street_builder._ready()`（故街区图截图走
`street_daynight_preview.tscn -- --shot <路径> [camx..lookz]`）。灰盒/main 的截图本班用了一个
**临时探针** `zz_nv_probe.gd/.tscn`（`--pshot/--pscene/--pvlayer/--pframes/--pcam`，全部 `--p`
前缀避免与 `--shot` 撞车），**收工已删除、未入库**。下一棒若需复拍，用法：

```
godot --path . res://scenes/levels/zz_nv_probe.tscn -- --pshot <out.png> \
  --pscene res://scenes/main.tscn --pframes 25 --nv-on [--pvlayer 0] [--pcam x y z lx ly lz]
```

## 九、附录：临时探针 `zz_nv_probe.gd` 全文（复拍用，勿直接入库）

```gdscript
extends Node
## 临时取证探针：给不含 --shot 处理的场景补截图能力，并可运行时覆写
## NightVisionOverlay 的 CanvasLayer.layer 做 HUD 层级对照。
## 参数一律 --p 前缀，避免与 street_builder 的 --shot 撞车。


func _ready() -> void:
	var args := OS.get_cmdline_user_args()
	var out_path := "user://nv_probe.png"
	var scene_path := "res://scenes/levels/greybox_arena.tscn"
	var frames := 20
	var vlayer := -1

	var i_shot := args.find("--pshot")
	if i_shot >= 0 and i_shot + 1 < args.size():
		out_path = args[i_shot + 1]
	var i_scene := args.find("--pscene")
	if i_scene >= 0 and i_scene + 1 < args.size():
		scene_path = args[i_scene + 1]
	var i_frames := args.find("--pframes")
	if i_frames >= 0 and i_frames + 1 < args.size():
		frames = args[i_frames + 1].to_int()
	var i_layer := args.find("--pvlayer")
	if i_layer >= 0 and i_layer + 1 < args.size():
		vlayer = args[i_layer + 1].to_int()

	var packed: PackedScene = load(scene_path)
	if packed == null:
		push_error("NV_PROBE load failed: %s" % scene_path)
		get_tree().quit(1)
		return
	add_child(packed.instantiate())

	var i_cam := args.find("--pcam")
	if i_cam >= 0 and i_cam + 6 < args.size():
		var cam := Camera3D.new()
		cam.name = "ProbeCamera"
		add_child(cam)
		cam.position = Vector3(args[i_cam + 1].to_float(), args[i_cam + 2].to_float(),
			args[i_cam + 3].to_float())
		cam.look_at(Vector3(args[i_cam + 4].to_float(), args[i_cam + 5].to_float(),
			args[i_cam + 6].to_float()))
		cam.current = true

	if vlayer >= 0:
		for child in find_children("NightVisionOverlay", "CanvasLayer", true, false):
			var cl := child as CanvasLayer
			cl.layer = vlayer
			print("NV_PROBE layer=%d path=%s" % [vlayer, cl.get_path()])

	for j in frames:
		await get_tree().process_frame
	var img := get_viewport().get_texture().get_image()
	print("NV_PROBE saved=%s err=%d size=%dx%d" % [out_path, img.save_png(out_path),
		img.get_width(), img.get_height()])
	get_tree().quit()
```

```
[ext_resource type="Script" path="res://scripts/levels/zz_nv_probe.gd" id="Script_probe"]

[node name="NvProbe" type="Node"]

```
