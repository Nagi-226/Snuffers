## ★ 明天第一优先：机主指出的三个问题

### 1. 敌人仍能隔墙发现+穿墙攻击（`2390757` 未根治）
- 机主原话："敌人仍能隔着墙看到以及穿墙打到我"。
- 排查方向：① 检查寄生体索敌的 raycast 碰撞掩码是否包含建筑墙体 layer（可能只查了某一层或 query 被 exclude 掉）；② 近战攻击判定是否做了视线/距离双重校验（孢子投掷是否穿墙）；③ 感知触发是否还有"听觉/半径触发"旁路无视遮挡。grep 起点：`godot/scripts/enemies/` 下 host_parasite 相关，搜 `ray_cast` / `intersect_ray` / `collision_mask` / `can_see` / `aggro`。
- 验收：vm 探针或试玩确认——玩家与敌人之间隔一栋建筑时敌人保持 idle/巡逻，贴墙射击不打穿。

### 2. 手枪握枪姿势"完全混乱，根本没握在握把上"（机主截图 3）
- 现象：ADS 视角下两只手贴在枪身两侧滑套位置，手指没包住握把。
- 根因方向：pose57_iter.json 的 IK 目标点把手拉到了正确位置（误差 1.8mm），但**手腕/掌的朝向（hand.R 旋转）和手指弯曲参数**是按"竖直步枪握把"调的，EM-57P 是无托手枪、握把前倾角不同；且双手握持手枪的左手应包在右手上/下侧而非对称镜像。
- 修法：pose57_iter.json 里调 hand.R/hand.L 旋转 + 手指弯曲角，用 `blender -b --python pose_arms.py -- ... pose57_iter.json` 迭代渲染（p57_*_fp.png 看第一人称效果）直到手真实包住握把，再跑 export_arms.py 导出。**参考：随便一个 FPS（Cod/CS2）手枪第一人称截图**——双手包握、枪身居中、拇指同向。
- 也可考虑直接降低难度：手枪改单手持枪（另一只手放下或扶腕），更容易做自然。

### 3. 步枪前手"向后弯折托着"而非"前伸握住护木"（机主截图 1/2）
- 现象：左臂肘部后收、手腕反折、从下方托着护木。
- 修法：pose68_iter.json 里把左手 IK 目标往前送（目标 y 现在是 0.14，护木更前段）+ hand.L 掌心朝上角 [0,0,-60] 减小/改轴向 + 手指弯曲加大让手指扣住护木上沿；肘部姿态可加 pre_bones 让肘自然下垂外张。参考 FPS 步枪第一人称：前臂前伸、手从侧下握护木、手指可见扣在护木侧面。
- 迭代闭环（同手枪）：改 json → pose_arms.py 渲染看 fp → 满意后 export_arms.py 导出 → `--headless --import` → vm-shot 实拍 → 机主验收。
