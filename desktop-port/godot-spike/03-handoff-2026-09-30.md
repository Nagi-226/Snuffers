## 三、给下一棒的注意事项

1. **`_ready` 顺序陷阱**（本次调研新发现，已写入方案 C3）：Godot 子节点 `_ready` 先于父节点。
   street_builder 是根脚本，其 `_apply_fog()` 会**覆盖**任何子节点驱动器先写的雾参数。
   昼夜域施工时 NIGHT 态干脆不写雾（让渡所有权），DAY 态须 await 一帧后再写。
2. `GameState.is_night` 默认 true 是当前 street_test 夜视门控可用的**隐性兜底**——
   集成后必须由驱动器显式维护，否则模式切换后门控静默失效（翻车模式⑦）。
3. night_vision_overlay 的 N 键在**有玩家在场时让位** player_controller（灰盒集成先例），
   街区图若挂 overlay 注意别双头切换。
4. 本棒未跑 audit_map（零场景改动，A/B/C 理应维持全零）；L1 在 commit 前按串行纪律执行，
