## 〇、双队视觉总纲：一黑一白，一武一文

两支特遣队在同一个雨夜街区里先后进场，视觉上必须构成对照关系：

| | 熄烛-01「雷暴」 | 熄烛-02「浓雾」 |
|---|---|---|
| 职能 | 硬打击（破拆组/执炬） | 认知滤网（捕梦网作业） |
| 视觉印象 | **军事的、进攻的、沉默的** | **市政的、日常的、哪里不对劲的** |
| 主色 | 哑光黑 + 深灰 + 血红点缀 | 工装白 + 荧光黄 + 淡紫点缀 |
| 恐怖来源 | 一看就知道是杀戮机器 | 看了半天才意识到不是抢修队 |
| 徽记 | 刺绣臂章，血色全彩 | 黑白魔术贴版，且**故意贴歪/贴在不规范位置**（伪装不需要标准） |

一句设计母题：**雷暴过处，浓雾收场。前者是夜空里的闪电，后者是闪电之后弥漫的雾——目击者最后记得的，应该只是「那晚来了抢修队」。**

## 一、熄烛-01「雷暴」美术设定

### 1.1 执炬单兵（玩家第一人称视角的本体 + 镜像/影子/队友可见形态）

**火炬架护甲 · 城区战配置**（区别于漫画线的深空战配置——同一平台的任务化换装，设定内自洽）：

- **整体廓形**：全覆式外骨骼，比深空版更贴身、更矮廓——城区战要过门框、进楼道。肩甲收窄，胸甲前板微隆（深汲微型供能舱），腿部外骨骼液压杆外露
- **材质语言**：哑光陶瓷复合装甲板（防破片）+ 关节处黑色防弹纤维编织层；**雨夜湿反光是核心材质卖点**——装甲板只反光、不发光
- **头盔**：全包裹，无外露面部；面罩为「萤」HUD 的内投影面，外部看是一片暗色复眼式镜片，仅在激活瞬间掠过一线青光
- **生命体征光带**：躯干与四肢的蓝色脉动光带（承袭漫画线 v4 的死亡空间式语言）——城区版亮度调低 60%，夜视仪下才醒目，裸眼仅隐约可见。敌我识别与「人味」的平衡点
- **徽记**：左肩甲外侧，刺绣织地 EDAA 徽记全彩版（黑底、血色锐星、贯星长剑、红绳剑柄）——作战单位用全彩，与征调单位的黑白魔术贴形成身份层级
- **气象代号标识**：右肩甲内侧，「雷暴」队徽——风格化积雨云+一道折线闪电，低可视度暗灰印刷，近距才可见

### 1.2 武器系统（城区战负载）

| 装备 | 视觉设定 |
|---|---|
| 制式步枪 | **刻意常规**：无科幻发光件、无夸张外形——防线条令「不显眼」。哑光黑，战术手电/镭指为唯一外设 |
| RPG 发射筒 | 同样常规军规外观，筒身有一行极小的白漆编号（器械库配发编号，格式与普通军队不同——彩蛋细节） |
| M50 光束发射模块 | 右前臂挂点，方匣形，发射口为深紫色晶体聚焦环（唯一承认「这不是人类科技」的视觉件）；**激活时才有存在感的装备** |
| 备选模块挂点 | 背部左右各一：零点重力场牵引（抓钩状）/ 静滞力场（球头天线状）/ 凝相锚（三棱钉状）——Sprint 后续内容的视觉预留 |

### 1.3 配色板（雷暴）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主装甲 | `#1A1D21` 哑光黑 | 大面 |
| 次装甲 | `#3A4048` 深灰 | 板块分色、护膝肘 |
| 纤维层 | `#0E0F11` 近黑 | 关节、内衬 |
| 徽记血星 | `#8E1B1B` 暗血红 | 点缀，绝不用于大面 |
| 生命光带 | `#4FC3E8` 冰蓝（低亮） | 脉动光源 |
| HUD 青光 | `#7FE3D0` 青玉 | 萤投影、面罩反光 |

### 1.4 载具：反重力飞行器（回收/投送平台）

- 轮廓参考扁平菱形飞梭，无旋翼无尾焰，悬停时仅有底部淡淡的空气扭曲
- **夜间城市作业涂装**：全哑光黑，无航灯；或启用「假民航频闪」模式（红绿航灯位置故意与任何现役机型不一致——给航空爱好者的彩蛋）
- 内部无驾驶舱视角（玩家全程看不到驾驶员——它不需要）

## 二、熄烛-02「浓雾」美术设定

### 2.1 作业人员（非战斗单位，恐怖感来自「日常中的错位」）

- **基础层**：白色连体式「疾控消杀」防护服——但细看处处不对：品牌标签不存在、拉链走向与市售款相反、胸前单位名是**不存在的机构**（如「市特别环境评估中心」，完美呼应 UNSHAM 的 sham 自白）
- **外层**：荧光黄反光背心——背心上的反光条排列成普通人不会注意的样式，但拉近看，部分背心的反光条拼出变体的 EDAA 锐星（仅限近景镜头/特定光照下可辨，彩蛋级细节）
- **头部**：透明防护面屏 + 口罩。面屏内侧有极淡的 HUD 反光（他们也配「萤」——舆论处/档案处的外勤同样是探员）
- **行为设计**（比服装更重要的美术层）：动作永远不紧不慢、三人间距永远相等、从不互相交谈——玩家若在后续关卡以第三视角遇见浓雾作业组，**「哪里不对」的感觉就是美术目标**

### 2.2 捕梦网器械（认知滤网·现场端）

- **形态**：工程仪器语言——三脚架 + 手持终端，外观介于全站仪与环境监测仪之间。路人扫一眼会当成测绘设备，这正是设计目的
- **激活特征**：顶端展开一环**淡紫色辉光**（`#B9A7E8`，全设定中唯一分配给「认知作业」的颜色），辉光扫过即完成清除——无声、无风、无闪光
- **手持端**：勘查灯形补盲器，用于室内/近距离个体作业，同样淡紫光
- **铁律的视觉表达**：捕梦网只能清除不能植入——器械通体**没有任何输入设备**（无键盘、无触屏），只有「启动」一个物理键

### 2.3 载具与现场物料

- **白色市政工程车**：仿燃气公司涂装（黄斜纹腰线），车门单位名与人员防护服同一虚构机构；车顶警示灯的闪烁频率是错的（每 0.7 秒一次——标准件是 1 秒，彩蛋）
- **现场物料**：红白隔离带、假的「燃气泄漏 禁止靠近」告示牌（字体是规范的，公章是模糊的）、锥桶——**全部是真货**。浓雾的恐怖在于：他们带来的日常物料都是真的，只有人是假的
- **配色板（浓雾）**：工装白 `#E8E6E0` / 荧光黄 `#D9E021` / 淡紫辉光 `#B9A7E8` / 隔离带红 `#C22F2F` / 雾灰 `#6B7178`

## 三、通用规范

### 3.1 徽记使用层级（依据设定 v0.9 徽记条款）

| 单位 | 版本 |
|---|---|
| 熄烛者各特遣队（正式作战） | 刺绣全彩版（黑底血色） |
| 整编部队 / 征调单位 | 黑白魔术贴版 |
| 浓雾作业组 | 黑白魔术贴版，且允许不规范佩戴（伪装纪律） |
| 文件/简报/UI | 单色线稿版（HUD、档案卡水印用） |

### 3.2 气象代号视觉系统

六支特遣队各配一枚气象符号章（低可视度）：雷暴＝积雨云+折线闪电 / 浓雾＝三条波浪横线 / 日食＝缺环 / 潮汐＝新月+波浪 / 冻雨＝雨滴+雪花叠印 / 极光＝弧光带。**游戏中作为队伍识别 HUD 图标与关卡 logo 复用**。

### 3.3 出图工艺继承（漫画线 v1→v4 教训）

1. AI 只出视觉底图，**一切文字/数字用 Pillow 确定性叠加**（中文字体 msyhbd.ttc），不让 AI 渲染中文
2. 「AI生成」水印用采样+噪点填充工艺裁除（v4 已验证）
3. 参考图三件套已定调：伊藤润二视觉污染感（生物组织）× 死亡空间工业重甲（护甲）× 伪纪实档案美学（构图与色调）——本辑两张概念图即按此母本生成

### 3.4 与游戏管线的对接

- 本辑配色板即 G4 美术期的贴图/光照基准（夜雨湿反光是居民区等场景的主材质语言）
- 执炬城区护甲 = 玩家第一人称视角模型的 G4 目标外观；当前 spike 期不投入（§11.3 既定）
- 浓雾组在首发任务《回南》中仅以「终检检疫哨」形态出现（白+荧光黄+淡紫光，三件套即可辨识）——**低成本先露脸，完整形象留给后续关卡**
