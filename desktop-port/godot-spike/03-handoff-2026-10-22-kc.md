## ★ 三个 4.6.2 引擎坑（探针实证，后续 Agent 必读）

1. **BILLBOARD_PARTICLES 材质下 `ParticleProcessMaterial.scale_min/max` 完全不生效**——粒子按 draw pass 网格原始尺寸渲染。子弹火星的 BULLET_SPARK_SCALE_* 此前从未真正生效（一直渲染 1m 方块），机主两次「缩小火星体积」裁决实际未落地。本棒已修：粒径烘进双 draw pass 网格（explosion_fx + player_combat_fx 同修）。
2. **BILLBOARD_ENABLED 会剥离节点 scale**（billboard 重建 modelview 时归一化基向量）——billboard 面片要改尺寸必须写 `QuadMesh.size`，不能写 `node.scale`。
3. **透明/ADD 材质在雾中会被整面漂白成雾色方片**——特效材质必须 `disable_fog = true`（4.6 已有此成员；注意官方 stable 文档页是 4.7+，`use_scale_3d` 等 API 在 4.6.2 不存在，别照抄文档）。
- 取证工具入库：`godot/tools/probe_explosion_fx.gd`（暗场分层隔离 + 定时截图，`-- <out_dir> <mode> <t>`，mode: full/no_smoke/smoke_only/no_sparks/sparks_only/加 `_fog` 后缀带雾）、`godot/tools/probe_fx_textures.gd`（程序纹理直出 PNG）。
