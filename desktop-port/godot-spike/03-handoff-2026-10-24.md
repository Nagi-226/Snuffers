### 2. 步兵动画状态机（代码准备）

`godot/scripts/enemies/infantry.gd`：

- 自动下钻 `BodyMesh` 绑定第一个 `AnimationPlayer`；剪辑契约固定为 `idle / walk / run / attack / death`。
- `PATROL → walk`，`ALERT / PEEK → idle`，`TAKE_COVER / ENGAGE → run`，孢子与近战均触发 `attack`，死亡触发 `death`。
- `idle / walk / run = LOOP_LINEAR`；`attack / death = LOOP_NONE`；攻击自然结束恢复当前状态剪辑。
- 死亡时先退出 `enemy` 组、清零 Body 与 HeadHitbox 的 collision layer/mask，再广播原有 `Events.enemy_died`；剪辑结束才 `queue_free()`，避免尸体挡弹/虚假命中/小地图残留。
- 旧无动画模型或无 `death` 剪辑时仍立即释放，原有伤害数值、攻击距离、视线判定和状态转移未改。

新增 `godot/tests/test_infantry_animation.gd`，21 项断言覆盖播放器绑定、五态映射、循环配置、两类攻击、攻击恢复、死亡碰撞/组清理、死亡结束释放、无播放器回退。
