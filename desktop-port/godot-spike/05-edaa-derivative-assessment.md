# 《废墟突围》→ EDAA 衍生游戏可行性评估与首个任务设计

> 文档性质：蜂后制作人评估 + 任务故事设计案（待机主裁决）
> 依据材料：`E:\EDAA\人类防线-组织框架设定文档-v0.9.md`（全本）、`.workbuddy\stories\AE-信使-活体行星-剧本-v0.1.md`（实际为 v0.2 内容）
> 评估对象：当前 dev_godot HEAD `1032472` 的可玩 demo（夜间废墟城镇 FPS：步枪/RPG、步兵/机枪手/碉堡/狙击手、趴下停火窗、夜视仪 N 键、昼夜切换、直升机定时撤离）
> 日期：2026-08-19

---

## 一、结论

**高度可行，适配度约八成，且与现有开发规划零冲突。**

Demo 的核心循环——「夜间潜入城镇废墟 → 与成建制敌对武装交火 → 限时撤离」——恰好就是 EDAA 体例下一场标准的**二级响应（接战）作业**，而玩家身份落在**熄烛-01「雷暴」特遣队**（人口密集城区硬打击，自接战至根除不超过 90 分钟）上严丝合缝。现有的直升机撤离倒计时机制，甚至可以直接叙事化为「雷暴 90 分钟硬时限」。

更关键的是：本评估**不要求 spike 期新增任何玩法系统**。全部改动分两层——叙事皮肤层（文案/UI 体例，spike 期可做可不做）与美术层（G4 后，正好落在 §11.3「美术放 G4 后」的既定决策里）。玩法数值框架（§7 手感对照表）一个数都不用动。

## 二、现有机制 → EDAA 设定映射表

| Demo 现状 | EDAA 映射 | 改造量 |
|---|---|---|
| 玩家：步枪 + RPG + 趴下 + 医疗包 | **3级执炬**（破拆组骨干）着「火炬架」护甲的常规破拆负载；RPG 可保留为常规爆破弹药，也可在美术期换皮为 M50 光束模块 | 零（叙事化即可） |
| 夜视仪 N 键（绿色磷光占位效果） | 「**萤**」隐形眼镜 HUD 的暗视模式——2级提灯/3级执炬制式配装，设定原生支持 | 零（占位效果已在） |
| 昼夜双模式（T 切换 / DayNightController） | 行动时间窗：摧毁作业默认夜间执行（静默优先），白天模式可作「侦查回放/简报推演」 | 零 |
| 步兵 ×6 / 机枪手 ×2 / 狙击手 ×1 | 被异常操控的**宿主武装**（失踪人员转化）——解释人形敌人为什么守卫废墟 | 美术期加变异视觉层 |
| 碉堡机枪（趴下停火 7s 窗，已裁决采 A） | 宿主集结节点/巢穴外围防御器官；停火窗叙事化为「宿主轴过热排空周期」 | 零 |
| 直升机撤离（定时 + 撤离区） | **雷暴 90 分钟硬时限** + 维度转移/反重力飞行器回收窗口 | 零（文案改皮） |
| 击杀计数 + HUD | 作业进度「宿主清除数」；结算界面改为**档案卡体例** | 极小（UI 文案） |
| 「看不见敌人却被连续攻击」（alerted 机制，A 方案补表现中） | 异常的感知反制——「深汲是从深处取水，深处亦回以注视」：异常也在感知你 | 已在施工队列 |
| 灰盒废墟城镇（碉堡/小屋/狙击塔/掩体点） | 设篱后的废弃城区现场 | 美术期贴图换皮 |

**不适配/需新设的缺口**（如实列出）：

1. **缺 AE 本体目标**——当前任务终点是「撤离」，EDAA 教义是「摧毁」。需把任务终点升级为「摧毁巢穴核心 → 撤离」，核心可复用现有碉堡/结构体加一个可摧毁目标点（Sprint 3 任务链串联时顺带做，成本低）。
2. **缺认知滤网维度**——EDAA 的「静默优先于曝光」可做成结算评价维度（如：作业时长、警报触发次数 → 滤网负荷评级），属于加分项而非必需。
3. **敌人外观**——现役人类士兵模型与「宿主」设定在美术期前存在叙事断层，spike 期可用简报文案先行覆盖（「目标区域武装人员已被 AE-XXX 转化，按宿主处置」）。

## 三、首个任务故事设计：《行动代号·骤雨》

> 严格按 EDAA 档案体例编写；威胁定级压到**游动级**（界级故事是《呼吸的邻居》那个量级的事，衍生游戏的首个任务不该动用执火/裁决者——调动铁律：二级响应以下不见执火）。

### 3.1 任务简报卡（游戏开场界面直接可用）

```
【异常存在信息 · 行动简报】
登记编号：AE-431「檐雨」
威胁定级：游动（Roaming）
处置状态：待摧毁（封锁中）
建档单位：东亚-太平洋防线区 · ██站
响应等级：二级（接战）
参战单位：熄烛-01「雷暴」先遣破拆组（你）/ 篱笆部队（外围）/ 提灯人（情报）
代号释义：该 AE 依附于废弃城区建筑檐角与管线，夜间活性化，
         沿建筑表面「流淌」转移——提灯人报告原话："像雨顺着屋檐走。"
```

### 3.2 背景故事（简报文本/加载界面）

三周前，██市老城区改造拆迁片区开始有人失踪。提灯人小组以疾控流调员身份进场核实，确认 AE-431「檐雨」——一类依附建筑结构的无实体-半实体混合型异常，夜间自檐角、管线、地下室渗出活性化，将被困于废墟内的流浪人员与私自进场的拾荒者**转化为宿主武装**，用于驱赶接近巢穴核心的外来者。

篱笆部队已完成三街区隔离周界，对外掩饰叙事为「危房爆破拆除工程」（补丁协议第一针已投放）。但昨夜周界传感器记录到宿主武装开始**成建制构筑工事**——它在学习怎么防守。封锁处评估：任其发展，设篱将转为长期围困（熄烛-05「冻雨」剧本），宿主规模将超出捕梦网作业的覆盖上限。

司令官批示一句话：「**趁它还只是一场雨，把它擦了。**」

你是熄烛-01「雷暴」的破拆组先遣，3级执炬。今夜 02:00 维度转移投送至废墟东侧出生点，任务窗口 90 分钟——这就是雷暴的全部含义。

### 3.3 任务链（直接对应现有玩法结构）

| 阶段 | 玩法内容（现状复用） | 叙事包装 |
|---|---|---|
| ① 渗透 | 夜间出生点出发，夜视仪 N 键可用（黑夜模式） | 「萤」HUD 上线，视野内宿主单位高亮标记 |
| ② 清剿外围 | 步兵 ×6 依托掩体点交火；狙击手占据塔楼 | 宿主警戒网——「它在看着你打它的手」 |
| ③ 拔除火力点 | 机枪手 ×2 + 碉堡（趴下停火 7s 窗是关键机制） | 宿主轴防御工事；碉堡是「檐雨」的一个渗出口 |
| ④ 摧毁核心 | RPG/持续火力摧毁巢穴核心（**新增可摧毁目标点**，Sprint 3 实现） | 核心位于废墟中央地下，半实体化的「檐雨」本体聚集处 |
| ⑤ 撤离 | 倒计时内抵达撤离区，直升机/转移回收 | 雷暴时限耗尽前脱离；篱笆部队随后进场消杀 |

### 3.4 结算界面（档案卡体例，UI 换皮即可）

```
【作业结算 · 熄烛-01「雷暴」】
宿主清除：██ / 9        作业用时：██:██
核心摧毁：确认 / 未确认   警报触发：█ 次
认知滤网负荷评估：低 / 中 / 高（由用时与警报数派生）
处置状态变更：待摧毁 → 已根除
档案处备注（红色笔迹）：
  "宿主均为失踪登记人口。清除的不是他们，是他们身体里的雨。"
```

### 3.5 叙事钩子（为后续任务留的线头）

1. 碉堡停火窗的「过热排空」实际是檐雨在**回抽感知**——它在把先遣队的战斗数据传回某个更大的东西（接《呼吸的邻居》的「它们不是第一批」）；
2. 核心摧毁后现场残留一段不属于任何已知频段的高维回波——谛听阵列后来比对出，它与 1962 年事故原型机的失控信号**同构**；
3. 简报中「██站」的站名始终是涂黑的——零号案的卡片上，这个站名曾经出现过。
