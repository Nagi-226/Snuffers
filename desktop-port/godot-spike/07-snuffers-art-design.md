## 〇、双队视觉总纲：一黑一白，一武一文

两支特遣队在同一个雨夜街区里先后进场，视觉上必须构成对照关系：

| | 熄烛-01「雷暴」 | 熄烛-02「浓雾」 |
|---|---|---|
| 职能 | 硬打击（破拆组/执炬） | 认知滤网（捕梦网作业） |
| 视觉印象 | **军事的、进攻的、沉默的** | **仪器的、流程的、没有人味的** |
| 主色 | 哑光黑 + 深灰 + 血红点缀 | 灰白 + 浅灰分色 + 淡紫点缀 |
| 恐怖来源 | 一看就知道是杀戮机器 | 一模一样的一张张「空白脸」 |
| 徽记 | **肩＝EDAA 全彩刺绣／胸＝雷暴队徽**（闪电＋火炬＋冲击波，蓝橙） | **肩＝EDAA／胸＝队徽**，两枚**皆为黑白魔术贴版**（非作战单位无全彩资格——徽记层级即身份层级） |
| 手持物 | 制式雷械——EM-68A「霹雳」／机枪手 EM-68L「殷雷」 | 一人 EM-57S-1「雹·Ⅰ」＋ 一人手持捕梦网器械；**枪永远低垂不上肩** |

一句设计母题：**雷暴过处，浓雾收场。前者是夜空里的黑色闪电，后者是闪电之后漫进来的灰白色的雾——前者让你不敢看，后者让你记不住。**

## 一、熄烛-01「雷暴」美术设定

### 1.1 执炬单兵（玩家第一人称视角的本体 + 镜像/影子/队友可见形态）

**火炬架护甲 · 城区战配置**（区别于漫画线的深空战配置——同一平台的任务化换装，设定内自洽）：

- **整体廓形**：全覆式外骨骼，比深空版更贴身、更矮廓——城区战要过门框、进楼道。肩甲收窄，胸甲前板微隆（深汲微型供能舱），腿部外骨骼液压杆外露
- **材质语言**：哑光陶瓷复合装甲板（防破片）+ 关节处黑色防弹纤维编织层；**雨夜湿反光是核心材质卖点**——装甲板只反光、不发光
- **头盔**：全包裹，无外露面部；面罩为「萤」HUD 的内投影面，外部看是一片暗色复眼式镜片，仅在激活瞬间掠过一线青光
- **生命体征光带**：躯干与四肢的蓝色脉动光带（承袭漫画线 v4 的死亡空间式语言）——城区版亮度调低 60%，夜视仪下才醒目，裸眼仅隐约可见。敌我识别与「人味」的平衡点
- **★ 标识制式：肩＝EDAA／胸＝本队（机主指令 2026-10-18，八支特遣队统一）**：**肩甲（通常为左肩）＝EDAA 防线徽记；胸前甲板（胸膛正位）＝本队「刺绣魔术贴式」队标识**。两枚皆为刺绣魔术贴形态（可拆卸、可换佩），非喷涂。
  - **为什么要改**：原制式是"双肩章"（一侧 EDAA／另一侧本队）。但单人三分之四视角**通常只露一侧肩甲**，一张图永远只看得见一半，只能靠 AO 双图（`-a`／`-b` 两版）凑齐。改成"肩＋胸"后，**一张图就同时呈现两级标识**，AO 双图作废——这是制式的净收益，不是为了省事。
  - **EDAA 侧（肩）**：刺绣织地 EDAA 徽记全彩版（黑底、血色锐星、贯星长剑、红绳剑柄）——作战单位用全彩，与征调单位的黑白魔术贴形成层级
  - **本队侧（胸）**：本队气象代号队徽刺绣贴。雷暴＝闪电＋火炬＋冲击波同心圆（蓝橙）／浓雾＝蛛网＋眼（黑白）。**胸前是"正面朝向观者"的甲板，失焦最少、辨识度最高的一块面**
  - **实质**：EDAA 徽记回答「你属于防线」，队徽回答「你属于哪一支」——一枚是归属，一枚是职能。分置两处而不是叠在一处，正是为了让两个问题都能一眼读完
  - **★ 出图工艺注**：胸前必须**空出来**——底图持枪姿态不得让枪身或手臂横过胸膛，否则胸章无处可贴。v7 底图因此改为**腰胯横持**（枪身侧面对镜头，既能读全枪型、又不挡胸）。见 §3.3

### 1.2 武器系统（城区战负载）

| 装备 | 视觉设定 |
|---|---|
| 制式步枪（突入组） | **EM-68A「霹雳」**——EDAA 雷械谱系无托构型；哑黑机匣 + 灰白陶瓷装甲板 + 护木六边/圆开孔 + 冷青电弧光；60 发通用弹匣。**注**：雷暴是雷械全谱档列装部队，用「E 系列」而非常规军械（原稿「刻意常规」口径作废——见 EDAA 设定 5.3.0） |
| 班用机枪（机枪手） | **EM-68L「殷雷」**——同族班用持续压制火力；粗短机匣 + 提把 + 下挂 600 发弹箱 + 折叠两脚架 + 枪口制退器。一个突击班组内至少一具 |
| M50 光束发射模块 | 右前臂挂点，方匣形，发射口为深紫色晶体聚焦环（唯一承认「这不是人类科技」的视觉件）；**激活时才有存在感的装备** |
| 备选模块挂点 | 背部左右各一：零点重力场牵引（抓钩状）/ 静滞力场（球头天线状）/ 凝相锚（三棱钉状）——Sprint 后续内容的视觉预留 |

> **武器视觉总纲（沿用）**：雷械是 EDAA 的看家语汇，但出图时**只保留冷青电弧光与六边开孔两项识别件**，其余一律落地为写实军工质感——防线条令要求「近看不吓人」，发光件是激活时才有存在感的。

- 轮廓参考扁平菱形飞梭，无旋翼无尾焰，悬停时仅有底部淡淡的空气扭曲
- **夜间城市作业涂装**：全哑光黑，无航灯；或启用「假民航频闪」模式（红绿航灯位置故意与任何现役机型不一致——给航空爱好者的彩蛋）
- 内部无驾驶舱视角（玩家全程看不到驾驶员——它不需要）

## 二、熄烛-02「浓雾」美术设定

### 2.1 作业人员 · 「垂帘」滤网作业护甲（v1.1 重做，机主指令）

> 设定合规声明：火炬架是 3 级执炬专属（设定 5.1），浓雾为舆论处/档案处联合编成，**不得与火炬架同平台**。故浓雾护甲为逆格处同一逆向工程工业体系下的**同源异型平台**——命名「**垂帘**」（雷暴之后，垂下帘幕），由保障处配发。视觉上它是火炬架的灰白色近亲，但每一条差异都在说「我不是作战甲」。

- **整体廓形**：与火炬架同世代的全覆式装甲语言，但**一切攻击性切角被磨圆**——雷暴的装甲板是刀刃般的斜面，垂帘是医疗器械般的圆角；肩甲更窄更平，胸甲**无供能舱隆起**（没有 M50 需要供能），整体比雷暴薄一圈、轻一圈
- **配色**：哑光陶瓷白大面 + 浅灰板块分色——风暴兵式的「空白制服感」，但落地为写实军工质感：板面有细微的工程塑料颗粒纹理，不是亮面玩具
- **头盔**（与雷暴最显眼的区分点）：**整面不透光白色面甲**，仅一条横向贯通的暗色面窗带——比雷暴的复眼镜片更「无脸」。一排浓雾站开时，你面对的不是几个人，是几个**相同的空位**
- **光环系统**：生命体征光带改为**淡紫色**（`#B9A7E8`，认知作业的专属色），且不是条状是**环状**——背包两侧、腰侧、手腕各一枚光环，与捕梦网器械的辉光环同形同色：他们身上的每一个光圈都在提醒「这人是一件仪器的附件」
- **徽记**：**双标识制式，与雷暴同规**——**肩甲 EDAA 徽记黑白魔术贴版／胸前甲板浓雾本队刺绣贴**（蛛网＋眼，去色为黑白）。层级上浓雾属黑白魔术贴档（非作战单位无全彩资格，这是层级不是疏忽）
- **配枪（v1.2 修订，机主指令 2026-10-12；v1.4 校正枪型细节）**：**不再是「无武器化」**。低烈度档列装——作业组内**一人持 EM-57S-1「雹·Ⅰ」冲锋枪**（传统布局、**哑黑机匣下体 + 灰白陶瓷上护板**、冷青细缝光（**不是长条亮管**）、**护木单排 5 个六边形开孔**、**炮口上下双筒：上细管带槽制退器 + 下粗短筒**、骨架托带梯形镂空与六边青嵌），**另一人持手持捕梦网器械**（勘查灯形，右腰佩挂，拔握姿势与拔枪相同）。改口理由：认知作业现场需要「能随身带、能近距压制、能在人群里不显眼」的自卫手段；**捕梦网仍是他们的主要工具，枪只是「配枪」**——「**他们的配枪不杀人，只清场**」这句保留，指的是捕梦网
- **★ 层级的视觉表达**：即便持枪，浓雾的枪也永远**低垂、不上肩、不指人**——枪在浓雾手里是「一件被规定必须带着的东西」，不是「一件武器」。这个姿态差是雷暴／浓雾在剪影上最重要的分野
- **背包**：捕梦网数据/供能背包，表面印刷网格坐标纹（测绘仪器语言），顶部一枚折叠三脚架挂点
- **周界外罩衣**（保留 v1 伪装设定，降级为可选外层）：跨周界机动时可在垂帘护甲外罩白色「疾控消杀」连体服 + 荧光黄背心（虚构机构「市特别环境评估中心」，呼应 UNSHAM 的 sham 自白）——**进入周界即脱罩衣**：雾不需要对内伪装
- **行为设计**（比装甲更重要的美术层）：动作永远不紧不慢、三人间距永远相等、从不互相交谈——**「哪里不对」的感觉就是美术目标**

### 2.2 捕梦网器械（认知滤网·现场端）

- **形态**：工程仪器语言——三脚架 + 手持终端，外观介于全站仪与环境监测仪之间。路人扫一眼会当成测绘设备，这正是设计目的
- **激活特征**：顶端展开一环**淡紫色辉光**（与护甲光环同形同色），辉光扫过即完成清除——无声、无风、无闪光
- **手持端**：勘查灯形补盲器，用于室内/近距离个体作业，佩于右腰如配枪
- **铁律的视觉表达**：捕梦网只能清除不能植入——器械通体**没有任何输入设备**（无键盘、无触屏），只有「启动」一个物理键

### 2.3 载具与现场物料

- **白色市政工程车**：仿燃气公司涂装（黄斜纹腰线），车门单位名为同一虚构机构；车顶警示灯的闪烁频率是错的（每 0.7 秒一次——标准件是 1 秒，彩蛋）
- **现场物料**：红白隔离带、假的「燃气泄漏 禁止靠近」告示牌（字体是规范的，公章是模糊的）、锥桶——**全部是真货**。浓雾的恐怖在于：他们带来的日常物料都是真的，只有人是假的
- **配色板（浓雾）**：陶瓷白 `#D8D9D6` / 浅灰分色 `#9A9EA3` / 暗色面窗带 `#14161A` / 淡紫光环 `#B9A7E8` / 隔离带红 `#C22F2F` / 雾灰 `#6B7178`

## 三、通用规范

### 3.1 徽记使用层级（依据设定 v0.9 徽记条款）

**唯一图样基准：`godot/assets/branding/edaa_emblem.png`**（机主原创，源文件 `E:\EDAA\EDAA徽记.png`，2026-08-19 入库）。一切臂章/章徽/UI 水印/开头画面均以此图样为准制作，禁止另行设计变体重绘。图样要素：黑底刺绣织地、血色锐星钉入开裂经纬地球、长剑贯星入地（剑柄缠红绳、柄首缀血珠）、外环格言三词 IDENTIFY · ERADICATE · SILENCE 以菱形钉扣相隔、不镌年份——与设定 v0.9 徽记条款逐字吻合。

| 单位 | 版本 |
|---|---|
| 熄烛者各特遣队·**EDAA 侧肩章**（正式作战，含雷暴） | 刺绣全彩版（黑底血色）——即基准图样本体 |
| 熄烛者各特遣队·**本队侧胸章** | 本队气象代号队徽，**刺绣魔术贴式**（可拆卸换佩），佩戴于**胸前甲板正位** |
| 整编部队 / 征调单位 | 黑白魔术贴版（基准图样去色重制） |
| 浓雾作业组（垂帘护甲） | **两枚皆黑白魔术贴版**，规范佩戴 |
| 文件/简报/UI | 单色线稿版（HUD、档案卡水印用） |

> **★ 双标识铁律（机主指令 2026-10-18，取代 v1.2 双肩章制式）**：**八支特遣队成员一律**「**肩甲 EDAA 徽记 ／ 胸前甲板本队刺绣贴**」。EDAA 徽记回答归属，队徽回答职能。两枚都是刺绣魔术贴件（挂载式），不是喷涂——这决定了它们的视觉特征：**边缘有织地厚度、有缝线轮廓、与甲面之间有一道细微投影**。
>
> **分置两处的理由**：肩与胸是正面视角下**两处不重叠的平整甲面**，一图可同时读到；若两枚都上肩，就永远只能看到一枚。

**游戏开头画面规范（机主指令 2026-08-19）**：游戏启动/标题画面以 EDAA 徽记为核心背景——纯黑底，徽记居中缓显（刺绣纹理特写 → 拉远至全貌），格言三词随拉远依次可读；标题与菜单叠加其上。首发任务《回南》的简报卡亦以徽记为水印底。

### 3.2 气象代号视觉系统

六支特遣队各配一枚气象符号章（低可视度）：雷暴＝积雨云+折线闪电 / 浓雾＝三条波浪横线 / 日食＝缺环 / 潮汐＝新月+波浪 / 冻雨＝雨滴+雪花叠印 / 极光＝弧光带。**游戏中作为队伍识别 HUD 图标与关卡 logo 复用**。

### 3.3 出图工艺继承（漫画线 v1→v4 教训）

1. AI 只出视觉底图，**一切文字/数字用 Pillow 确定性叠加**（中文字体 msyhbd.ttc），不让 AI 渲染中文
2. 「AI生成」水印用采样+噪点填充工艺裁除（v4 已验证）
3. 参考图三件套已定调：伊藤润二视觉污染感（生物组织）× 死亡空间工业重甲（护甲）× 伪纪实档案美学（构图与色调）——本辑概念图即按此母本生成；浓雾护甲追加第四条母本：风暴兵式「空白制服感」的写实军工转译
4. **★★ 徽记叠加工艺 —— 「真实贴片」六步法（v7，2026-10-18 定稿，脚本 `concept-art/fix_armbands_v7.py`）**
   - **不让 AI 画徽记**——AI 会画成模糊色块。徽记一律用 **Pillow 确定性叠加**
   - **★ 底图上那个「AI 占位章」其实就是 `edaa_emblem.png`**（红星＋IDENTIFY·ERADICATE·SILENCE＋地球＋剑）。故 EDAA 侧**不是叠新章，而是用基准图原位覆盖＋提亮**，位置天然吻合
   - **队徽贴源**：`E:\EDAA\特遣队徽记\刺绣贴\熄烛-0X-<队名>-刺绣贴.png`（1024×1024 **RGB 无 alpha**、圆形章体落在**方形深底**上、角落带 AI 水印）
   - **★ v5 被否定的原因＝只有圆形裁切**，没有布料物理特征，所以像"抠图粗糙 PS"。**必须走完整六步**：
     1. **轮廓**＝椭圆 ＋ 4 个随机相位正弦叠加（freqs 2/3/5/7）→ 剪裁不齐的不规则边
     2. **包边缝线**＝沿轮廓内侧一圈细密斜向短针（偏 35°、间距≈针长 0.7 倍、针色接近底色）
     3. **厚度投影**＝轮廓整体偏移（方向随该图主光）＋ 深色模糊
     4. **织物 weave**＝斜向经纬噪声
     5. **边缘接触阴影**＝轮廓内侧一圈渐暗
     6. **贴片本体**＝最上层
   - **★★ 轮廓必须是椭圆，不是正圆**（v7 修正）：圆贴片贴在**倾斜甲面**上，投影必然是椭圆。v6 的 `cloth_outline` 用 `min(w,h)` 算半径 → 只能出正圆；旧图章体 46×54 差 8px 尚不明显，v7 肩章 49×67 就会露上下各 10px。**改法：rx、ry 分别按 w、h 取**，box 的宽高比即透视比
   - **★★ 织纹掩膜必须亮度中性**：`weave_noise` 中心值取 **255**、只向下浅波纹；若中心取 128 再做 multiply，等于把贴片整体压暗 ~50% 并让织纹盖过图案。周期须**尺寸自适应**（目标约 7 个波纹周期），固定值会产生摩尔纹网格
   - **★★ 浅底 vs 深底的色调处理截然不同**：
     - **深色甲面（雷暴）**→ 徽记源图**降饱和 0.80—0.88 ＋ 提织纹 0.40 ＋ 提亮 1.10**。不降饱和的话，队徽那颗高饱和蓝会像"发光贴纸"
     - **浅色甲面（浓雾白甲）**→ 深色徽记直接压上去就是**一块黑斑**（机主否定的"黑圈"）。必须**反相成浅色刺绣贴**：
       · EDAA 章（对比度尚可）→ 反相 ＋ 压缩到 [152, 152+92] ＋ 提对比 1.9
       · 浓雾队徽（**极暗**：灰度均值 45.6、90% 像素 <96）→ 反相 ＋ **S 曲线**。★ v7 曲线换成 `(0,96)(120,112)(141,126)(175,196)(215,228)(255,248)`——v6.2 的旧曲线 `(0,244)…(255,118)` **映射方向是反的**（底色被压暗、线迹被提亮），在小尺寸胸章上表现为"灰盘＋亮线"，读不出蛛网。判据：**底要亮、线要暗**
   - **★ 胸章小于 ~60px 时辨识度崩**：60px 见方以下，蛛网/眼这类细线迹会被缩放抹平。**胸章定稿 66px 见方**（雷暴胸章 56px 仍可，因其队徽是块面而非细线）
   - **★ 贴片必须完全盖住原章**：`inset` 决定可见半径（`0.5-inset` 倍）。v6.1 用 0.062 时只有 0.438 倍，在「box≈原章直径」时盖不满 → 露出原章外圈形成黑圈。**定稿 inset=0.030**（0.470 倍），box 再各向外放 8%
   - **★ 轮廓抖动幅度要随尺寸收敛**：`wobble=0.028` 在大贴片上会成"花瓣边"（一眼假）；v7 定稿 **0.016**
   - **★ 定位法：原图打 10px（细）＋50px（粗）双向标尺网格 ＋ 1:1 高倍裁剪目检**。**缩略图与实图尺寸不同，目测比例必串**——本轮曾因按显示尺寸换算，把浓雾左人肩章读偏 75px。可靠做法：裁成 150×150 @5x（输出 750px，显示不缩放），网格线标**原图绝对坐标**，直接在图上读
   - **★ 自动检测（梯度／环形拟合）在本项目失效**——装甲纹理会被一并算入，得出虚大值；目检最可靠
   - **★ 水印清除分两路**：右下「AI生成/WORKBUDDY」是**厚体白字** → 逐行左右插值（取掩膜两端外侧 8px 均值）＋ **彩色区膨胀 9px 保护**（否则穿过水印区的发光圆环会被填掉、边缘出毛刺）；左下「AI生成」是**细体半透明** → 中值背景替换（逐行插值会给细字拉出横向条纹）。**亮度阈值取 150 而非 62**——湿地面有大量高光碎点（70—120、低饱和），按 62 判会把碎点一起填掉，整块区域发闷并留下可见方形明度差
