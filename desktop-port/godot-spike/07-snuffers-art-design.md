## 〇、双队视觉总纲：一黑一白，一武一文

两支特遣队在同一个雨夜街区里先后进场，视觉上必须构成对照关系：

| | 熄烛-01「雷暴」 | 熄烛-02「浓雾」 |
|---|---|---|
| 职能 | 硬打击（破拆组/执炬） | 认知滤网（捕梦网作业） |
| 视觉印象 | **军事的、进攻的、沉默的** | **仪器的、流程的、没有人味的** |
| 主色 | 哑光黑 + 深灰 + 血红点缀 | 灰白 + 浅灰分色 + 淡紫点缀 |
| 恐怖来源 | 一看就知道是杀戮机器 | 一模一样的一张张「空白脸」 |
| 徽记 | 刺绣臂章，血色全彩 | 黑白魔术贴版（非作战单位无全彩资格——徽记层级即身份层级） |

一句设计母题：**雷暴过处，浓雾收场。前者是夜空里的黑色闪电，后者是闪电之后漫进来的灰白色的雾——前者让你不敢看，后者让你记不住。**

## 一、熄烛-01「雷暴」美术设定

### 1.1 执炬单兵（玩家第一人称视角的本体 + 镜像/影子/队友可见形态）

**火炬架护甲 · 城区战配置**（区别于漫画线的深空战配置——同一平台的任务化换装，设定内自洽）：

- **整体廓形**：全覆式外骨骼，比深空版更贴身、更矮廓——城区战要过门框、进楼道。肩甲收窄，胸甲前板微隆（深汲微型供能舱），腿部外骨骼液压杆外露
- **材质语言**：哑光陶瓷复合装甲板（防破片）+ 关节处黑色防弹纤维编织层；**雨夜湿反光是核心材质卖点**——装甲板只反光、不发光
- **头盔**：全包裹，无外露面部；面罩为「萤」HUD 的内投影面，外部看是一片暗色复眼式镜片，仅在激活瞬间掠过一线青光
- **生命体征光带**：躯干与四肢的蓝色脉动光带（承袭漫画线 v4 的死亡空间式语言）——城区版亮度调低 60%，夜视仪下才醒目，裸眼仅隐约可见。敌我识别与「人味」的平衡点
- **徽记**：左肩甲外侧，刺绣织地 EDAA 徽记全彩版（黑底、血色锐星、贯星长剑、红绳剑柄）——作战单位用全彩，与征调单位的黑白魔术贴形成身份层级
- **气象代号标识**：右肩甲内侧，「雷暴」队徽——风格化积雨云+一道折线闪电，低可视度暗灰印刷，近距才可见

### 1.2 武器系统（城区战负载）

| 装备 | 视觉设定 |
|---|---|
| 制式步枪 | **刻意常规**：无科幻发光件、无夸张外形——防线条令「不显眼」。哑光黑，战术手电/镭指为唯一外设 |
| RPG 发射筒 | 同样常规军规外观，筒身有一行极小的白漆编号（器械库配发编号，格式与普通军队不同——彩蛋细节） |
| M50 光束发射模块 | 右前臂挂点，方匣形，发射口为深紫色晶体聚焦环（唯一承认「这不是人类科技」的视觉件）；**激活时才有存在感的装备** |
| 备选模块挂点 | 背部左右各一：零点重力场牵引（抓钩状）/ 静滞力场（球头天线状）/ 凝相锚（三棱钉状）——Sprint 后续内容的视觉预留 |

### 1.3 配色板（雷暴）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主装甲 | `#1A1D21` 哑光黑 | 大面 |
| 次装甲 | `#3A4048` 深灰 | 板块分色、护膝肘 |
| 纤维层 | `#0E0F11` 近黑 | 关节、内衬 |
| 徽记血星 | `#8E1B1B` 暗血红 | 点缀，绝不用于大面 |
| 生命光带 | `#4FC3E8` 冰蓝（低亮） | 脉动光源 |
| HUD 青光 | `#7FE3D0` 青玉 | 萤投影、面罩反光 |

### 1.4 载具：反重力飞行器（回收/投送平台）

- 轮廓参考扁平菱形飞梭，无旋翼无尾焰，悬停时仅有底部淡淡的空气扭曲
- **夜间城市作业涂装**：全哑光黑，无航灯；或启用「假民航频闪」模式（红绿航灯位置故意与任何现役机型不一致——给航空爱好者的彩蛋）
- 内部无驾驶舱视角（玩家全程看不到驾驶员——它不需要）

## 二、熄烛-02「浓雾」美术设定

### 2.1 作业人员 · 「垂帘」滤网作业护甲（v1.1 重做，机主指令）

> 设定合规声明：火炬架是 3 级执炬专属（设定 5.1），浓雾为舆论处/档案处联合编成，**不得与火炬架同平台**。故浓雾护甲为逆格处同一逆向工程工业体系下的**同源异型平台**——命名「**垂帘**」（雷暴之后，垂下帘幕），由保障处配发。视觉上它是火炬架的灰白色近亲，但每一条差异都在说「我不是作战甲」。

- **整体廓形**：与火炬架同世代的全覆式装甲语言，但**一切攻击性切角被磨圆**——雷暴的装甲板是刀刃般的斜面，垂帘是医疗器械般的圆角；肩甲更窄更平，胸甲**无供能舱隆起**（没有 M50 需要供能），整体比雷暴薄一圈、轻一圈
- **配色**：哑光陶瓷白大面 + 浅灰板块分色——风暴兵式的「空白制服感」，但落地为写实军工质感：板面有细微的工程塑料颗粒纹理，不是亮面玩具
- **头盔**（与雷暴最显眼的区分点）：**整面不透光白色面甲**，仅一条横向贯通的暗色面窗带——比雷暴的复眼镜片更「无脸」。一排浓雾站开时，你面对的不是几个人，是几个**相同的空位**
- **光环系统**：生命体征光带改为**淡紫色**（`#B9A7E8`，认知作业的专属色），且不是条状是**环状**——背包两侧、腰侧、手腕各一枚光环，与捕梦网器械的辉光环同形同色：他们身上的每一个光圈都在提醒「这人是一件仪器的附件」
- **徽记**：黑白魔术贴版，规范佩戴（与整编部队同级待遇——非作战单位没有全彩徽记，这是层级不是疏忽）
- **无武器化**：全身**没有任何武器挂点**；右腰的佩挂位挂着勘查灯形手持捕梦网，拔握姿势与拔枪完全相同——**他们的「配枪」不杀人，只清场**
- **背包**：捕梦网数据/供能背包，表面印刷网格坐标纹（测绘仪器语言），顶部一枚折叠三脚架挂点
- **周界外罩衣**（保留 v1 伪装设定，降级为可选外层）：跨周界机动时可在垂帘护甲外罩白色「疾控消杀」连体服 + 荧光黄背心（虚构机构「市特别环境评估中心」，呼应 UNSHAM 的 sham 自白）——**进入周界即脱罩衣**：雾不需要对内伪装
- **行为设计**（比装甲更重要的美术层）：动作永远不紧不慢、三人间距永远相等、从不互相交谈——**「哪里不对」的感觉就是美术目标**

### 2.2 捕梦网器械（认知滤网·现场端）

- **形态**：工程仪器语言——三脚架 + 手持终端，外观介于全站仪与环境监测仪之间。路人扫一眼会当成测绘设备，这正是设计目的
- **激活特征**：顶端展开一环**淡紫色辉光**（与护甲光环同形同色），辉光扫过即完成清除——无声、无风、无闪光
- **手持端**：勘查灯形补盲器，用于室内/近距离个体作业，佩于右腰如配枪
- **铁律的视觉表达**：捕梦网只能清除不能植入——器械通体**没有任何输入设备**（无键盘、无触屏），只有「启动」一个物理键

### 2.3 载具与现场物料

- **白色市政工程车**：仿燃气公司涂装（黄斜纹腰线），车门单位名为同一虚构机构；车顶警示灯的闪烁频率是错的（每 0.7 秒一次——标准件是 1 秒，彩蛋）
- **现场物料**：红白隔离带、假的「燃气泄漏 禁止靠近」告示牌（字体是规范的，公章是模糊的）、锥桶——**全部是真货**。浓雾的恐怖在于：他们带来的日常物料都是真的，只有人是假的
- **配色板（浓雾）**：陶瓷白 `#D8D9D6` / 浅灰分色 `#9A9EA3` / 暗色面窗带 `#14161A` / 淡紫光环 `#B9A7E8` / 隔离带红 `#C22F2F` / 雾灰 `#6B7178`

## 三、通用规范

### 3.1 徽记使用层级（依据设定 v0.9 徽记条款）

**唯一图样基准：`godot/assets/branding/edaa_emblem.png`**（机主原创，源文件 `E:\EDAA\EDAA徽记.png`，2026-08-19 入库）。一切臂章/章徽/UI 水印/开头画面均以此图样为准制作，禁止另行设计变体重绘。图样要素：黑底刺绣织地、血色锐星钉入开裂经纬地球、长剑贯星入地（剑柄缠红绳、柄首缀血珠）、外环格言三词 IDENTIFY · ERADICATE · SILENCE 以菱形钉扣相隔、不镌年份——与设定 v0.9 徽记条款逐字吻合。

| 单位 | 版本 |
|---|---|
| 熄烛者各特遣队（正式作战，含雷暴） | 刺绣全彩版（黑底血色）——即基准图样本体 |
| 整编部队 / 征调单位 | 黑白魔术贴版（基准图样去色重制） |
| 浓雾作业组（垂帘护甲） | 黑白魔术贴版，规范佩戴 |
| 文件/简报/UI | 单色线稿版（HUD、档案卡水印用） |

**游戏开头画面规范（机主指令 2026-08-19）**：游戏启动/标题画面以 EDAA 徽记为核心背景——纯黑底，徽记居中缓显（刺绣纹理特写 → 拉远至全貌），格言三词随拉远依次可读；标题与菜单叠加其上。首发任务《回南》的简报卡亦以徽记为水印底。

### 3.2 气象代号视觉系统

六支特遣队各配一枚气象符号章（低可视度）：雷暴＝积雨云+折线闪电 / 浓雾＝三条波浪横线 / 日食＝缺环 / 潮汐＝新月+波浪 / 冻雨＝雨滴+雪花叠印 / 极光＝弧光带。**游戏中作为队伍识别 HUD 图标与关卡 logo 复用**。

### 3.3 出图工艺继承（漫画线 v1→v4 教训）

1. AI 只出视觉底图，**一切文字/数字用 Pillow 确定性叠加**（中文字体 msyhbd.ttc），不让 AI 渲染中文
2. 「AI生成」水印用采样+噪点填充工艺裁除（v4 已验证）
3. 参考图三件套已定调：伊藤润二视觉污染感（生物组织）× 死亡空间工业重甲（护甲）× 伪纪实档案美学（构图与色调）——本辑概念图即按此母本生成；浓雾护甲追加第四条母本：风暴兵式「空白制服感」的写实军工转译

### 3.4 与游戏管线的对接

- 本辑配色板即 G4 美术期的贴图/光照基准（夜雨湿反光是居民区等场景的主材质语言）
- 执炬城区护甲 = 玩家第一人称视角模型的 G4 目标外观；当前 spike 期不投入（§11.3 既定）
- 浓雾组在首发任务《回南》中以「终检检疫哨」形态首次登场：**两具垂帘护甲 + 一台三脚架捕梦网 + 一枚淡紫光环**即可构成完整辨识（灰白在夜雨场景里天然高对比，比黑色雷暴更好做）——低成本先露脸，群像与罩衣形态留给后续关卡
- 雷暴（黑/进攻/锐角）与垂帘（白/流程/圆角）构成**同世代双平台视觉族**——后续日食、冻雨等队的美术均在此双平台语言上派生
